# Deal Flow

Chart-first multifamily BOE pro forma — same math as **Deal Pro Forma**, Earnings Flow–style Sankey UI.

- Preloaded sample: **111 First Street** · $25M · 200 units
- Sticky metrics: Cap Rate, CoC, YoC, DSCR, IRR, Equity Multiple
- localStorage saves · standalone PWA
- Methodology inspired by public Tactica RES tutorials

```bash
npm install
npm test
npm run build
npm run screens   # WebKit 440×956 @3 → screens/
```

**Not published.** Distinct from Deal Pro Forma (form-first): this app is chart-first.
